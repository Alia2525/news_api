##Опис завддання: 

Створіть Rest Api для новин дані та інше можете обирати довільно.REST API для новин на FastAPI.

## Запуск проєкту

pip install -r requirements.txt
uvicorn main:app --reload
Перейти за посиланням та в пошуковому меню додати docs,
приклад адреси: http://127.0.0.1:8000/docs

Основні маршрути:
GET /news — отримати всі новини
GET /news/{news_id} — отримати одну новину по ID
POST /news — створити новину
PUT /news/{news_id} — оновити новину
DELETE /news/{news_id} — видалити новину
GET /news/category/{category} — пошук по категорії
GET /news/author/{author} — пошук по автору
GET /news/published — тільки опубліковані новини
Наприклад:
Відкрити GET /news
Натиснути кнопку Try it out
Потім Execute
Буде список усіх новин
Cancel - закриє новини

# News API

Проєкт реалізований на FastAPI та дозволяє працювати з новинами.

## Основний функціонал

- Отримання всіх новин
- Отримання новини по ID
- Додавання нової новини
- Повне оновлення новини
- Часткове оновлення новини
- Видалення новини
- Пошук новин по категорії
- Пошук новин по автору
- Отримання тільки опублікованих новин
- Отримання тільки неопублікованих новин
- Пошук новин по ключовому слову
- Пошук новин по даті
- Сортування новин по даті
- Перегляд статистики новин
- Автоматичне створення ID

## Новий функціонал

У проєкт було додано:

1. PATCH-запит для часткового оновлення новини.
2. Пошук по ключовому слову в заголовку або тексті.
3. Фільтрацію новин по даті.
4. Сортування новин по даті створення.
5. Endpoint для перегляду статистики.
6. Endpoint для перегляду неопублікованих новин.
7. Автоматичне створення ID при додаванні нової новини.
